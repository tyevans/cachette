## Why

**A graded reader review is the only measurement the project has of whether the
reference serves its audience.** The first round was read by a developer who was
given one address and nothing else. It graded seven dimensions and scored the
first action at 1 of 5. Every repair it named was concrete and quoted the page.

The repairs are made. Nothing has measured them. A second round reads the
repaired page under the same conditions and grades the same seven dimensions, so
the two rounds compare.

**The rubric the first round was graded against is not in the tree.** The review
cites it, and no file holds it. This item writes it down before the second round
runs, so the grade means the same thing twice.

**Three dimensions the first round could not reach are still open.** They are
the ones the prose quadrants own: no tutorial, no how-to guide and no
explanation page exists.[^1] A second round should say plainly which of its
findings the reference can fix and which need a page that nobody has written.
