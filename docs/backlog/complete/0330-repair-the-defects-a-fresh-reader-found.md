## Why

**A developer who was given the address of the published reference, and nothing
else, could not build a world.** The reader read the page six times, wrote a
five-line program, and stopped at line three. The page documents the `World`
class in detail and never says how to make one. Everything else on the page is
downstream of a call the reader cannot write.

**The page also cited a call it never published.** The error class for a bad
configuration says that the `World` constructor raises it, and it named "the
world settings", a term that appears nowhere else. So the error prose asserts an
interface that the class prose omits. A reader reads that as a defect in the
build rather than as a choice.

**A product record states the need.** A developer must be able to use the
control plane without reading its source.[^1] The reader's next move was to clone
the repository and read the Rust source for the constructor, which is the move
this reference exists to prevent.

## Impact review

**Governed by.** ADR-0107 D1, D2 and D3.[^2]

**D1, the reference is generated by an import of the compiled module.** This
item wrote no page. Every repair went into a Rust doc comment, and the
documentation build published it.

**D2, the prose of a member lives in the Rust doc comment.** A constructor is
the case the record did not cover, because the binding library replaces the doc
comment of a constructor with the standard interpreter sentence. A register
recorded the mechanism.[^3] The prose now lives in the doc comment of the class,
which is a doc comment of the bindings crate, so D2 holds without amendment. A
decision register row records the choice and the options.[^4]

**D3, the type stub carries prose only where the module provides none.** This
item wrote nothing into the stub.

**Blockers.** One opened. Nothing in the tree says which name a reader installs,
and the obvious name belongs to another project on the public index.[^5]

**Records created.** None. The work states no new constraint. It repairs prose
under a record that already binds where the prose lives.

## What done means

- The rendered reference names every parameter of the `World` constructor and
  of the `Camera` constructor, with its type, its default and its bound.
- The rendered reference names the audience, gives commands that install the
  package, and says that no other documentation page exists.
- The rendered reference says that the resource kinds and the ground kinds are
  two scales that overlap, and that an overlapping number is not refused.
- The rendered reference gives the radius ceiling of a window census as a
  number, in the verb entry and in the error entry.
- A test reads every documented default, bound and ceiling through the public
  interface, and fails when the code moves one.
- The documentation build, the documentation probe, the record checks, the
  Python lint and the Python tests all pass.

## What this item did not do

**It did not change any binding.** The overlapping kind scales stay integers.
The decision register holds the interface question, its options and a
recommendation.[^4]

**It did not write a tutorial, a how-to guide or an explanation page.** Three
other items own those.[^6]
